# Paws & Preferences 

A mobile-first swipe app to discover what kind of cats you like.
Swipe right to **Like**, swipe left to **Dislike**. After all cards, see a summary + liked gallery.

## Live Demo
https://hritheqal.github.io/paws-preferences/

## Repository
https://github.com/hritheqal/paws-preferences

## Features
- Swipe gestures (touch + mouse)
- Like/Dislike buttons
- Undo (revert last swipe)
- Keyboard shortcuts: ← dislike, → like, Backspace / U undo
- Summary screen with liked count + liked cat gallery
- Images sourced from Cataas

## Tech Stack
- React + TypeScript + Vite
- Framer Motion
